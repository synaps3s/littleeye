Agent Configuration Quick Start

Follow these commands on your Linux host to register it with the dashboard and run drift checks:

  1. Install LittleEye dependencies & source files on the host machine.
  2. Initialize the baseline snapshot. This captures the pristine config of services, files, env vars, packages, and listening ports:
    python3 -m littleeye.agent.cli --config config.yaml init
  3. Run the drift check. This compares the current state to the baseline and pushes updates to this dashboard:
    python3 -m littleeye.agent.cli --config config.yaml check
